The installed MCP 0.2.32 was checked with locally test-signed snapshots. Each listed exact transition was found offline and appeared in `get_upgrade_plan` when tested on its own with zero plan HTTP transactions. The wrong-package-manager and empty-snapshot controls were exercised. The recipes wait for maintainer review and the [existing Cache v2 publication process](KNOWLEDGE_CACHE_V2.md).

The [machine-readable review bundle](../knowledge/review/cache-v2-candidates-2026-11-24.json) contains all 37 v2 records with their pinned Git receipts. The installed reader found all 37 exact records in the same locally test-signed snapshot. All 33 distinct exact requests returned matching advice in `get_upgrade_plan` with zero HTTP transactions. The compact response omitted four additional exact matches and four major-line candidates across the 33 requests. For the TypeScript 5.9.2 → 6.0.3 example, `get_shared_migration_knowledge_batch` returned all three exact records while the plan showed one. See the [TypeScript replay receipt](https://github.com/levencode-labs/deploom-npm/pull/75).

The producer's fixture check passed against each exact fixture head with the public registry check stubbed for the offline proof. Its trusted-main gate rejected every draft. Admission still requires maintainer review, trusted fixture ancestry and the publisher's public registry checks.

The Vite example verified a version decision. Its exact old Vue plugin blocked the Vite-only update under strict peer resolution. Moving the plugin as part of the update preserved compilation. The other recipes supply scoped edits or checks from the evidence tested in each fixture. See the [Vite peer fixture](https://github.com/levencode-labs/deploom-npm/pull/68).
