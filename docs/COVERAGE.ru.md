## Повторная генерация

```sh
python cache/coverage_map.py
python cache/coverage_map.py --check
```

Запустите из корня репозитория с зависимостями и потребителем из `.github/actions/setup-cache-consumer`. Команда не выполняет миграции и не обращается в сеть. CI отклоняет устаревшие JSON/Markdown. Для проверки фактически скачанных опубликованных данных передайте `--published-dir <export>` с каталогами v2/v3; для существующего кэша клиента — `--local-cache <cache-root>`. Сохраняйте такой отдельный отчёт через `--output-dir <directory>`; значения публикации и кэша не выводятся из подготовленного корпуса.
