# Scoped knowledge review inputs

`evidence-scopes.json` is the explicit per-record review ledger for the parallel
signed v3 edition. It binds each classification to an exact legacy record and a
complete manifest of its retained Git fixture inputs. It is not generated by
guessing from record titles or receipt check labels.

The source corpus stays in `../v2/records.json` for strict legacy compatibility.
`cache/shards_v3.py` verifies the ledger and publishes both editions together.
An absent or changed review prevents publication.

See [the v3 contract and review procedure](../../docs/KNOWLEDGE_CACHE_V3.md) for
the evidence levels, exact hash serialization, scope limits, compatibility
checks, and release order.
